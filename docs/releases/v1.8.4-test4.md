# iPhoneMirror v1.8.4-test4

这是 1.8.4 系列的第 4 个测试版，重点验证有线/无线反向控制在多设备和切换场景下的稳定性，以及旧版 iOS 的配对兼容性。

## 反向控制

- 有线、无线和蓝牙反向控制在启动、停止和切换期间保持互斥，避免多个传输同时接管输入。
- 触控与键盘事件按选中的设备路由，不再把事件发送到另一个设备的桥接器。
- 桥接器回调增加实例校验，旧会话停止后不会污染新会话状态。
- 指针移出镜像预览后仍会在最后一个有效位置释放 USB 触控。

## 兼容性与窗口交互

- 为较旧 iOS 增加 RemotePairing 回退路径。
- 全屏预览中的 Escape 优先退出全屏，不会被反向控制转发到手机。
- 快捷键设置保存失败时恢复完整设置快照。

## 验证

- 扩展应用逻辑测试和 USB 桥接测试，覆盖设备定向路由、回调生命周期、触控释放、Escape 处理和设置回滚。

This is the fourth test build in the 1.8.4 series. It focuses on reverse-control routing across wired and wireless sessions, older-iOS pairing compatibility, and preview-window input handling.

### Changed

- Keep wired, wireless, and Bluetooth reverse-control modes mutually exclusive during transitions.
- Route touch and keyboard events to the selected device and ignore stale bridge callbacks.

### Fixed

- Add a RemotePairing fallback for older iOS versions.
- Release USB touch at the last valid preview position when the pointer leaves the image.
- Make Escape exit full-screen previews before reverse-control keyboard routing.
- Restore the complete shortcut-settings snapshot if saving fails.

### Verification

- Extend application-logic and USB bridge tests for targeted routing, callback lifetime, touch release, Escape handling, and settings rollback.
